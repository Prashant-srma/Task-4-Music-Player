# Task 4 — Music Player using JavaScript

A responsive music player built with HTML, CSS and vanilla JavaScript.

## Features
- Play / pause
- Next / previous
- Song title, artist and duration
- Progress bar with seeking
- Volume control
- Playlist
- Autoplay
- Shuffle
- Add your own local audio files
- Responsive design

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Click **Add Songs** to add MP3/audio files from your computer.
4. Press Play.

The initial demo song uses a public SoundHelix MP3 URL, so internet access is needed for that demo track. Local files work directly in the browser.

## Technologies
- HTML5
- CSS3
- JavaScript
- HTML5 `<audio>` API
